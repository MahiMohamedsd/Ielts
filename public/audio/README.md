# Listening audio

Drop the four recorded (or TTS-generated) MP3 files here, named exactly:

- `listening-part1.mp3` — Part 1, British accent
- `listening-part2.mp3` — Part 2, Australian accent
- `listening-part3.mp3` — Part 3, Canadian accent
- `listening-part4.mp3` — Part 4, Irish accent

~64–96kbps is plenty for speech and keeps load times low on mobile data.

Until a file is present, the player on `/listening` falls back to the browser's built-in
text-to-speech so the page is still fully usable end to end.
